Что такое домен?
  Сайт открывается по адресу http://ot-pb.by/ (раньше был IP http://207.154.238.178/).
  После покупки домена ot-pb.by люди смогут заходить так:
    https://ot-pb.by/
  Это выглядит профессионально и удобно для визиток и рассылок.

Стоимость: примерно 33–42 белорусских рубля в год (.by домен).

───────────────────────────────────────────────────────────────
ШАГ 1. ПРОВЕРИТЬ, СВОБОДЕН ЛИ ДОМЕН
───────────────────────────────────────────────────────────────

Зайдите на один из сайтов регистраторов:

  • https://hoster.by/   — в поиске введите: ot-pb.by
  • https://active.by/   — то же самое

Если написано «свободен» / «доступен для регистрации» — можно покупать.
Если «занят» — выберите другой вариант (например ot-pb-bezopasnost.by).

───────────────────────────────────────────────────────────────
ШАГ 2. КУПИТЬ ДОМЕН (ВЫ ПЛАТИТЕ САМИ — АГЕНТ НЕ ПОКУПАЕТ)
───────────────────────────────────────────────────────────────

1. Зарегистрируйтесь на hoster.by или active.by (если ещё нет аккаунта).
2. Добавьте в корзину домен ot-pb.by на 1 год.
3. Оплатите картой или через ERIP (как удобно).
4. Дождитесь письма «домен зарегистрирован» — обычно 5–30 минут.

Владелец домена: лучше указать данные Viktor Dubovik (или ваши, если покупаете вы).

───────────────────────────────────────────────────────────────
ШАГ 3. НАСТРОИТЬ DNS (САМОЕ ВАЖНОЕ!)
───────────────────────────────────────────────────────────────

В личном кабинете регистратора найдите раздел:
  «DNS» / «Управление зоной» / «DNS-записи» для ot-pb.by

Добавьте ДВЕ записи типа A (если старые A-записи мешают — удалите их):

  ┌──────────┬──────┬───────────────────┬──────┐
  │ Тип      │ Имя  │ Значение (IP)     │ TTL  │
  ├──────────┼──────┼───────────────────┼──────┤
  │ A        │ @    │ 207.154.238.178   │ 3600 │
  │ A        │ www  │ 207.154.238.178   │ 3600 │
  └──────────┴──────┴───────────────────┴──────┘

  @  = сам домен ot-pb.by (без www)
  www = ot-pb.by с www в начале

Сохраните. Изменения распространяются от 15 минут до нескольких часов.

───────────────────────────────────────────────────────────────
ШАГ 4. ПРОВЕРИТЬ, ЧТО DNS ЗАРАБОТАЛ
───────────────────────────────────────────────────────────────

На компьютере откройте браузер и зайдите:
  http://ot-pb.by/

Должен открыться тот же сайт Дубовик, что и по IP.
Если «сайт не найден» — подождите ещё 30–60 минут и попробуйте снова.

Когда http://ot-pb.by/ открывается — напишите агенту в чат:
  «DNS готов»

───────────────────────────────────────────────────────────────
ШАГ 5. ВКЛЮЧИТЬ HTTPS (ЗАМОК В БРАУЗЕРЕ) — НА СЕРВЕРЕ
───────────────────────────────────────────────────────────────

Это делает агент или вы по SSH на сервере DigitalOcean.
Команда (одна строка):

  bash /var/www/dubovik/deploy/setup_ot_pb_domain.sh --https

Или если файлы ещё не на сервере — сначала git pull / копирование из репозитория.

Скрипт:
  • подключит nginx к домену ot-pb.by
  • получит бесплатный SSL-сертификат (Let's Encrypt / certbot)
  • заменит ссылки на сайте с IP на https://ot-pb.by/

После успеха сайт откроется так:
  https://ot-pb.by/
  https://www.ot-pb.by/

───────────────────────────────────────────────────────────────
ЧТО УЖЕ ПОДГОТОВЛЕНО В РЕПОЗИТОРИИ
───────────────────────────────────────────────────────────────

  deploy/nginx-ot-pb-by.conf       — настройка nginx для домена
  deploy/setup_ot_pb_domain.sh     — установка nginx + HTTPS
  deploy/update_site_urls_to_domain.sh — замена IP на домен в HTML

Торговые боты PRD-BOT этими скриптами НЕ затрагиваются.

───────────────────────────────────────────────────────────────
КРАТКИЙ ПЛАН «СЕГОДНЯ»
───────────────────────────────────────────────────────────────

  1. Зайти на hoster.by → проверить ot-pb.by → купить (~33–42 BYN)
  2. В DNS добавить A @ и A www → 207.154.238.178
  3. Подождать, пока http://ot-pb.by/ откроет сайт
  4. Написать агенту: «DNS готов»
  5. Агент включит HTTPS и обновит ссылки на визитке
